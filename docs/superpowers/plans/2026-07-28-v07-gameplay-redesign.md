# 今日の市長 v0.7 実装計画

## Goal

週単位の都市経営ループ、実額財政、4段階イベント、住民ストーリー、街表示、アニメ調ポン吉、スマホUIを実装し、Cloudflare PagesとD1の既存基盤へ統合する。

## 実装順序

1. v0.7状態と旧状態拒否
2. 財政台帳、週次収支、予測、市債、予備費
3. 重点方針、委任、週7フェーズ
4. 週次・任期・公約目標、12週選挙
5. 予告・調査・対処・続報イベント
6. 複数週の大型事業と地区投資
7. 固定住民の分岐ストーリー
8. 街の視覚状態とポン吉SVG
9. 重要政策と未確認リスク
10. スマホ5タブUIと二段階支出確認
11. クラウド保存バージョンゲートとPWA更新
12. 12週間統合テスト、コードレビュー、モバイル確認

## TDD

各機能は次の順で実施する。

1. 期待動作のテストを書く
2. テストが失敗することを確認する
3. 最小実装を行う
4. 対象テストを通す
5. 全体テストを通す
6. コードレビューで見つかった不具合には再現テストを追加して修正する
