# 今日の市長 v0.8 プレミアムホームUI設計

作成日: 2026-07-28
対象: `TI-06/today-mayor`

## 1. 目的

承認済みの完成イメージを基準に、スマートフォンの初期画面を高品質なゲームホームへ刷新する。現状の上部余白、重複見出し、仮素材感、情報の散在を解消し、次の行動・財政・街の状態・ポン吉を1画面の流れで理解できるようにする。

## 2. ホーム画面構成

上から次の順で表示する。

1. コンパクトヘッダー
   - `MAYOR'S OFFICE`
   - `今日の市長`
   - 通知ボタン
   - メニューボタン
2. 財政カード
   - 市予算
   - 今週収支
   - 翌週予測
   - 衣装コイン
3. 次の行動カード
   - フェーズに応じた見出し・説明
   - 主操作ボタン
   - アニメ調ポン吉
4. 街カード
   - 街のイラスト
   - 状態ラベル
   - 街タブへ遷移するボタン
5. 主要指標カード
   - 市民満足度 = 支持率
   - 経済発展度 = 経済
   - まちの魅力度 = 暮らし・環境・安心の平均
6. 今日の予定
   - 現在フェーズの予定時刻風表示
   - 操作内容
7. 下部ナビ
   - ホーム
   - お仕事（政策）
   - 市民の声
   - まちづくり
   - 記録

## 3. 上部余白の解消

- `body`および`.app-shell`の不要な上余白を削除する。
- 既存の共通ヘッダーは高さを抑え、ホーム画面のコンテンツと一体化する。
- アカウント名は常時表示せず、メニュー内へ移動する。
- メニューは三点ボタンからハンバーガーアイコンへ変更する。

## 4. ポン吉

ユーザー提供の透明PNGを正式なホーム用素材として使用する。

### 表現

- 3頭身のアニメ調タヌキ
- 大きな目、明確なタヌキ模様、大きな縞尻尾
- 手を振るポーズ
- 名前表示はカード内の小さなラベルにする

### アニメーション

軽量CSSのみで実装する。

- 全身の呼吸・上下動
- 手振りに見える小さな回転
- 尻尾の左右揺れ
- まばたき用オーバーレイ
- 成功時の軽いジャンプ
- 警告時の小さな揺れ
- `prefers-reduced-motion`では停止する

PNG本体の画質を維持し、モバイルでは最大表示幅を制御する。

## 5. 街カード

既存の街状態ロジックは維持する。描画は現在のSVGを高品質カードとして再配置し、建物、道路、川、車、人、天候、工事、災害表現を引き続き状態に連動させる。

- 車は道路レーン上のみ走行する。
- 街カード全体をタップ可能にし、街タブへ遷移する。
- ホームでは情報を詰め込みすぎず、詳細は街タブで表示する。

## 6. 主要指標

ホームでは5指標をそのまま横並びにせず、3枚の大きなカードへ整理する。

- 市民満足度: `support`
- 経済発展度: `economy`
- まちの魅力度: `(life + environment + safety) / 3`

暮らし・環境・安心の個別値は街・政策・記録画面で確認できるため、ゲームロジックは変更しない。

## 7. 操作性

- 主要タップ領域は44px以上。
- 360px幅でも横スクロールを発生させない。
- CTAはファーストビュー内に表示する。
- 下部ナビはSafe Areaを考慮する。
- 画面遷移ロジック、フェーズ処理、財政処理は変更しない。
