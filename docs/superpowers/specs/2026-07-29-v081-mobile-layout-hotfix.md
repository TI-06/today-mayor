# 今日の市長 v0.8.1 スマホレイアウト修正

## 原因

v0.8のホーム画面で、新しい`premium-action-card`に旧v0.7用の`next-action-card`クラスが併記されていた。

旧CSSの以下の指定が残存していたため、文章領域が104px幅のGrid列へ押し込まれていた。

```css
.next-action-card {
  display: grid;
  grid-template-columns: 104px minmax(0,1fr);
}
```

その結果、見出し、説明、主操作ボタンが縦書きのように折り返され、カードが異常に縦長になった。

## 修正

- ホーム画面のメインカードから旧`next-action-card`クラスを削除する。
- `premium-action-card`を独立したレイアウトとして扱う。
- 360px、390px、412px、430px幅で文章領域が最低55%確保されることをCSS回帰テストで確認する。
- v0.8.1へバージョンを更新してService Workerと静的アセットをキャッシュバストする。

## 完了条件

- メイン見出しが通常の横書きで2〜3行以内に収まる。
- 主操作ボタンが横長で表示される。
- ポン吉と文章が重ならない。
- 横スクロールが発生しない。
- 既存テストを含む`npm run verify`が成功する。
