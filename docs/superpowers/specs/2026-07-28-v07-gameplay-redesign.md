# 今日の市長 v0.7 ゲーム性刷新 設計書

作成日: 2026-07-28  
対象: `TI-06/today-mayor`  
バージョン: `0.7.0`

## 1. 目的

v0.6までの「1日3件の案件を順番に処理する」構造を廃止し、プレイヤーが市長として方針、予算、調査、大型事業、住民対応を主体的に決める週単位の都市経営ゲームへ再構成する。

解消対象:

- 案件を消化するだけの作業感
- 市予算、週次収支、支出後残高が確認できない問題
- 政策結果が街の見た目へ十分反映されない問題
- イベントが単発で終わり、準備や調査ができない問題
- 住民が好感度ゲージとしてしか機能していない問題
- タヌキ秘書ポン吉のキャラクター表現が弱い問題
- スマートフォンでの情報量と操作導線が整理されていない問題

## 2. スコープ

| 領域 | 実装内容 |
|---|---|
| コアループ | 週単位、1週間7〜10分、能動操作3〜5回 |
| 自動処理 | 軽微案件をポン吉が委任方針に従って処理 |
| 主体的行動 | 重点方針、重要政策、大型事業、地区投資、調査 |
| 目標 | 週次目標、任期目標、選挙公約 |
| キャラクター | 固定住民の複数週ストーリーと分岐 |
| 街 | 経済、環境、建設、災害を街のSVG表示へ反映 |
| イベント | 予告、調査、対処、続報の4段階 |
| 選択情報 | 確定費用は表示、将来リスクは一部非表示 |
| 演出 | ニュース速報、市民反応、週次ダイジェスト |
| 財政 | 市予算、台帳、週次収支、翌週予測、市債、予備費 |
| ポン吉 | 3頭身アニメ調SVG、目・耳・口・尻尾・書類のアニメーション |
| UI | スマートフォン最優先、固定資金バー、5タブ、下部アクション |

実装対象外:

- v0.6以前のセーブ移行、バックアップ、互換性維持
- Live2D、3D、WebGL
- 実広告・実決済プロバイダー接続
- 対戦、チャット、ユーザー間取引

## 3. 旧データ

v0.7は新規ゲームとして開始する。

- Local Storageキーは`today-mayor-v07`。
- 旧キー`today-mayor-v02`は読み込まない。
- D1から取得した`state.version`が`0.7.0`以外の場合は読み込まない。
- v0.7を保存した時点で`saves.state_json`を上書きする。

## 4. 週進行

フェーズ順:

1. `focus`: 月曜・重点方針と選挙公約
2. `policy`: 火曜・重要政策とポン吉の軽微案件処理
3. `preview`: 水曜・事件の予告と調査
4. `project`: 木曜・大型事業、地区投資、住民相談
5. `response`: 金曜・調査結果を踏まえた対処
6. `city`: 土曜・街の変化、事業進行、続報
7. `summary`: 日曜・週次決算、目標、選挙判定

必要な判断が未処理の場合、次フェーズへ進めない。事業、地区投資、住民回答は`project`フェーズでのみ確定できる。

## 5. 財政

単位は億円の整数。

初期値:

- 市予算: 550
- 予備費: 50
- 市債: 0

収入:

- 基礎市税
- 経済活動税収
- 観光・施設収入
- 重点方針効果
- 市債発行

支出:

- 行政基本費
- 継続政策費
- 事業維持費
- 調査費
- 緊急対応費
- 地区投資
- 市債利息

すべての資金変動を`ledgerEntries`へ記録し、`sourceId + settlementKey + week`で二重計上を防止する。週次決算も同一週では冪等にする。

財政状態:

- `healthy`: 通常
- `warning`: 市予算120未満、翌週予測80未満、市債400以上
- `crisis`: 市予算または翌週予測がマイナス、市債700以上
- `bankrupt`: 市予算-150以下、市債1000以上

支出前には初期費用、毎週費用、現在予算、実施後残高、翌週予測、予備費を表示し、確定操作を二段階にする。

## 6. 目標と選挙

- 週次目標: 毎週2〜3件
- 任期目標: 公約、予算、支持率
- 任期: 12週間
- 選挙評価50点以上で再選
- 未達成公約は減点
- 再選後は新しい公約を選び直す

## 7. イベント

各イベントは次を持つ。

- 予告文
- 2件以上の調査方法と調査費
- 3件程度の対処方法と対応費
- 調査、過去政策、フラグに応じた続報分岐
- ニュース文

初期イベント:

- 河川水位上昇
- 工場環境監査
- 観光ブーム
- 学校教室不足
- 電力需給ひっ迫
- マスコット炎上

政策の未確認リスクは、将来イベントの出現条件として実際に反映する。

## 8. 大型事業・地区

大型事業は調査、承認、工事、完成を複数週で進行する。初期費用と毎週費用を持ち、完成時に指標と街表示を更新する。

初期事業:

- 防災センター
- 駅前再開発
- 子育て支援拠点
- 防災河川公園
- デジタル市役所
- 港の観光朝市

各地区へ週1回20億円を重点配分できる。地区経験値が基準を超えるとレベルアップする。

## 9. 住民ストーリー

固定住民:

- 商店会長
- 子育て世帯代表
- 工場長
- 高校生徒会長

各ストーリーは3場面以上、2結末以上を持つ。過去選択、週、住民関係、フラグにより次の場面を解禁する。

## 10. 街とポン吉

街表示パラメータ:

- 天候
- 歩行者
- 観光客
- トラック
- 店舗照明
- 樹木
- 工事現場
- 閉鎖施設
- 冠水
- 装飾

ポン吉:

- 3頭身のアニメ調タヌキ
- 大きな目、黒い目元、縞尻尾、紺色の制服、葉っぱ帽子
- 通常、喜び、心配、焦り、誇り、疲労、怒り
- まばたき、耳、口、尻尾、書類、呼吸、ジャンプ、電卓リアクション
- `prefers-reduced-motion`対応

## 11. スマホUI

- 対象幅: 360、390、412px
- 横スクロール禁止
- 上部に市予算、収支、翌週予測、衣装コインを固定
- 下部にホーム、街、政策、市民、記録の5タブ
- 主要アクションは下部ナビの上へ固定し、重ねない
- タップ領域は44px以上、主要ボタンは50px以上
- 重要判断は下から出るアクションシート
- ダイアログはビューポート内に収める

## 12. モジュール

- `game/state.js`: v0.7状態
- `game/finance.js`: 台帳と決算

- `game/focus.js`: 重点方針と委任
- `game/goals.js`: 目標と選挙
- `game/policies.js`: 重要政策
- `game/projects.js`: 大型事業と地区投資
