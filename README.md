# 今日の市長 v0.7.1

タヌキ秘書「ポン吉」と一緒に、週単位で方針、予算、重要政策、事件、大型事業を判断するスマートフォン向け都市経営ゲームです。

## v0.7.1 初期画面ホットフィックス

- 最初に押すボタンを画面上部へ移動しました。
- 「方針未設定」表示からも重点方針を開けます。
- 0/0の空目標表示を廃止しました。
- 街とポン吉のビジュアルを刷新しました。
- CSS・JavaScript・Service Workerをバージョン更新し、古い画面キャッシュを残しません。

## v0.7のゲームループ

1週間を7〜10分で進めます。

1. 重点方針とポン吉への委任方針を決める
2. 重要政策を判断する
3. 事件の兆候を調査する
4. 大型事業または住民ストーリーを選ぶ
5. 調査結果から事件へ対処する
6. 街の変化を確認する
7. 週次決算、目標、ニュースを確認する

軽微な案件はポン吉が自動処理し、費用と結果を報告します。

## 財政

- 市予算、予備費、市債、週次収入、週次支出を億円単位で管理します。
- 政策や事業の実行前に、初期費用、毎週費用、実施後残高、翌週予測を表示します。
- 衣装用の葉っぱコインは市予算と完全に分離しています。
- 財政台帳からすべての収入と支出を確認できます。

## イベントと住民

事件は「予告・調査・対処・続報」の4段階です。調査へ費用を使うと、判断材料が増えます。固定住民には複数週にわたる分岐ストーリーがあります。

## ポン吉と街

ポン吉は3頭身のアニメ調タヌキ秘書です。まばたき、耳、尻尾、呼吸、喜び、焦り、決算リアクションを軽量SVGとCSSで表現します。政策、建設、災害、財政状態は街の建物、人通り、観光客、工事、天候へ反映されます。

## 旧セーブについて

v0.6以前のセーブデータは移行しません。v0.7は新規ゲームとして開始します。

- Local Storageキーは`today-mayor-v07`です。
- D1の保存状態が`version: "0.7.0"`でない場合は読み込みません。
- v0.7を保存すると、同じプレイヤーの`saves.state_json`をv0.7状態で上書きします。

## Cloudflare Pages設定

| 項目 | 値 |
|---|---|
| Framework preset | `None` |
| Production branch | `main` |
| Build command | `bash cloudflare-build.sh` |
| Build output directory | `site` |
| Root directory | 空欄 |

D1未設定でも端末保存でゲーム本体を遊べます。`site/_routes.json`によりPages Functionsの対象は`/api/*`だけです。Service Workerも`/api/*`をキャッシュしません。

## D1

1. D1データベース`today-mayor-db`を作成します。
2. D1コンソールで`schema.sql`を実行します。
3. PagesプロジェクトのD1 Binding名を`DB`にします。
4. 再デプロイします。

作成されるテーブルは`users`、`sessions`、`saves`、`choice_stats`、`rankings`です。`sqlite_sequence`はSQLiteが自動作成する内部テーブルです。

## ローカル検証

```bash
npm run verify
npm run serve
```

`site/js/app.js`、`site/styles.css`、イベント・住民データ、ポン吉SVGは、`src/generated/`の分割ソースから`npm run build`で生成します。圧縮ファイルやBase64復元は使用せず、単純なテキスト連結だけを行います。

## 広告・決済

実プロバイダーは接続していません。`window.TodayMayorMonetization`へ`showRewardedAd`と`purchase`を実装すると接続できます。本番課金前にWebhook検証、Turnstileまたはレート制限、利用規約、プライバシーポリシーが必要です。
